# 相关会话

展开会话后，详情下方请求 `GET /api/sessions/:id/related`。接口要求管理端登录，只比较**同一聊天端用户 ID**的会话；管理端账号 ID 不参与匹配。候选会话的 User 提问被提取为中英文词汇与中文双字片段，去除常见疑问词，再按集合交并比计算相似度。分数至少 0.15 才展示，按分数降序、创建时间倒序排列，最多五条。点击结果会打开目标会话，空结果显示「暂无相似会话」。

这是轻量、可解释的词汇匹配，用于回看重复主题；无法可靠识别没有共同词汇的同义问题。接口只读 PostgreSQL，同一次请求获取该聊天端用户的 User 消息，不逐个请求会话详情，也不把其他用户的会话纳入候选。测试覆盖排名、空正文、不同主题、跨用户隔离、无效会话以及登录要求。页面显示和真实语料的匹配质量由用户验收。
