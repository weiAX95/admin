# 会话问答对抽取

会话中的 assistant 回复获得 4–5 星评分后，服务端取该回复之前最近一条 user 消息作为问题，将回复作为候选答案，并保留对话上下文。候选进入现有评测候选池，与实验候选共用审核流程；只有管理员可审核、查看统计和导出。评分不足的候选不进入待审核列表。

在「评测候选池」选择「会话问答」，可按审核状态查看候选。审核时可以编辑问题和答案，选择保留并暂存到目标数据集，或丢弃。已暂存的候选仍可使用现有「发布」操作追加到不可变数据集版本。

原消息重新评分时会更新候选的星级和标签，但不会覆盖已审核的问题、答案或审核决定。评分降到 4 星以下时，该候选暂时不参与问答导出；重新升到 4 星以上后仍保留人工编辑结果。

「导出审核通过的会话问答 JSONL」导出当前所有分页中已暂存或已发布、且当前评分仍至少为 4 星的会话候选。每行包含稳定的 `caseKey`、`input`、`expectedOutput`、`context`、`tags`、`difficulty: 3` 和 `source: "session_extract"`，可在数据集导入页重新导入。实验候选、待审核、已丢弃及低分候选不会导出。

页面显示的人工审核通过率为当前高分会话候选中的「已暂存＋已发布」数量除以「已暂存＋已发布＋已丢弃」数量；没有已审核候选时显示「暂无样本」。此值是当前候选池快照，评分被修改后可能变化，并非不可变的历史质量报告。**目标 >70% 尚未通过真实会话样本验收**；自动化测试仅验证计算和导出行为，不能证明抽取准确率。
