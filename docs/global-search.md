# 全局搜索

管理端顶栏提供全局搜索，按 `⌘K` 或 `Ctrl+K` 打开。输入停止 160 毫秒后请求 `GET /api/search?query=关键词`，输入变化会忽略旧请求的结果。结果按任务、笔记、会话、实验、提示词和评测用例分组，各组最多 5 条；方向键选择、Enter 跳转、Esc 关闭。查询词去除首尾空格后须为 1–120 个 Unicode 字符，大小写不敏感，`%`、`_` 和反斜杠按普通字符搜索。

接口使用当前登录令牌。普通成员只能看到自己拥有的任务和自己上报的会话；其他四类沿用目前各模块对登录账号开放的读取范围。软删除的任务、笔记、实验和提示词不会出现。搜索直接查询 PostgreSQL，不加载完整业务对象；单次 SQL 设有 280 毫秒超时，超时时返回可重试的提示。

评测用例结果固定指向其数据集版本和 `caseKey`，详情仅查询一条用例，避免一次下载整个版本。会话结果指向该会话的行内详情。搜索是快捷入口，不替代各模块的完整筛选和分页。

可运行 `npm run benchmark:global-search` 重测性能。2026-10-13 在本地独立 PostgreSQL 测试库中，准备 10,000 条固定版本用例及 8,000 条其他记录，连续 30 次 HTTP 请求的中位数为 38 毫秒、p95 为 42 毫秒、最大 43 毫秒；这些数字不含前端 160 毫秒输入防抖，其他设备与数据分布需要单独测量。
