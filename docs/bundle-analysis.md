# 前端构建体积分析

运行 `npm run build:analyze`，构建完成后在本地打开 `dist/bundle-stats.html`。报告按依赖和输出包展示体积，可切换原始、gzip、Brotli 大小；普通 `npm run build` 不生成报告。`dist` 已被 Git 忽略，分析报告不会进入仓库或生产包。

使用依赖图时，先看入口包，再看各路由异步包。某依赖只出现在一个页面包中，说明它没有进入其他页面的首次下载；反复出现在共享包中的依赖则值得检查导入位置。Tree shaking 的效果以最终包中**实际保留**的模块为准，不能仅凭源文件中的 import 判断。

2026-11-16 在本机执行分析构建，TypeScript 和 Vite 构建通过。最大输出包依次包括通用 `index` 包约 874 kB、Markdown 编辑相关包约 773 kB、`fontkit` 包约 717 kB，以及入口相关 `index` 包约 393 kB（均为未压缩大小）。这些是后续拆包与按需加载的优先检查对象；包名由 Vite 生成，具体依赖以交互报告为准。此结果是**构建体积**，不代表 3G 首屏时间或浏览器渲染帧率，相关运行指标在最终性能验收中测量。
