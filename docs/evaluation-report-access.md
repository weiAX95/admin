# 回归报告访问边界

回归报告正文包含用例输入、上下文、参考答案、模型输出和指标分数。管理端登录并不自动赋予所有报告的读取权：`GET /api/experiment-batches/:id/report` 仅允许批次所属账号或管理员读取。`GET /api/experiment-baselines` 只列出当前账号的可用基线，管理员可见全部；执行回归时服务端再次验证所选基线的归属，不能通过直接提交别人的批次 ID 绕过候选列表。

主动创建的公开分享沿用独立令牌接口：有效令牌可读取对应报告，过期或撤销后失效。分享预览与创建仍由报告所属账号或管理员管理。回归测试覆盖直接猜测报告 ID、基线列表和执行复用的拒绝路径，以及所属账号和公开分享的正常路径。其他实验记录按现有“登录账号可查看与标注，创建者或管理员管理”的协作约定处理；本修复不改变该约定。
