# 仪表盘时间窗口

“今日”“本周”“本月”“近 30 天”“近 90 天”和保留的“近一年”均以**上海日历日**计算，本周从周一开始。自定义范围包含起止两日，最多 366 天。前端每次切换向 `GET /api/stats?start=YYYY-MM-DD&end=YYYY-MM-DD` 传参；日期缺失、逆序、无效或超出上限时服务端返回 400。自定义范围未填完整时不发全量请求，页面保留上次成功的统计结果并提示；更新失败也保留旧结果供重试。旧请求返回晚于新请求时不会覆盖新结果。

各面板的时间含义不同，页面工具栏也会说明：

| 面板 | 时间窗口口径 |
| --- | --- |
| 任务总数、状态分布、平均进度、分类进度、能力雷达 | **窗口内创建的任务**，显示它们的当前状态和进度；不是历史某日的状态快照 |
| 任务趋势、活动时间线、按天热力图 | 发生在窗口内的事件或有记录的历史进度 |
| 逾期预警 | 按现有 1.4 规则，展示全部当前逾期且未完成的任务，不因创建日期被隐藏 |
| 工时偏差率 | 按现有 2.10 规则，为全部有预估和实际记录任务的累计指标 |
| 热力图月视图、年视图 | 作为 1.7 的独立浏览模式，展示所选结束日期所在月或所在年的完整活动，不截断为窗口 |
| 快速操作入口 | 始终指向最近记录，不受统计窗口约束 |

接口测试验证上海跨日、周一起始、预设与自定义边界，以及切换后任务总数、状态、分类和平均进度变化；同时验证当前逾期任务仍完整展示。页面正式显示由用户验收。
