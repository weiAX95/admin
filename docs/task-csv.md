# 任务 CSV 数据约定

“任务快照”指任务本体在导出时的字段集合，包括标题、描述、分类、阶段、状态、优先级、日期、进度、清单、标签、资源、依赖、预估工时、版本、归属、时间戳与重复序列信息。数组和对象存为 JSON 单元格。工时记录、字段变更历史、关联笔记和实验是独立数据，不属于任务快照。

“导入副本”指从 CSV 创建的新任务。即使文件含有旧 ID、账号、版本和时间戳，导入也会生成新 ID，以当前登录账号为归属，重置版本和系统时间，并重算有效状态与清单进度。旧 ID 只用于同一文件内的依赖重映射。文件外依赖必须通过当前账号的访问权限和循环依赖校验；跳过某行后，依赖该行的其他行也会被判无效。导入不会修改已有任务。

重复任务实例保留重复标记和原次数，但其导入后的序列使用新 ID 且处于停止状态，不会触发自动补建。导入的清单子项也使用新 ID。重复配置中的快照仅供历史展示，不会驱动已停止的序列。

默认 CSV 导出包含完整任务快照；“仅导出当前可见列”按表格列顺序输出展示字段，任务列拆为标题、描述和标签，状态列拆为用户状态、有效状态和阻塞原因。选择列和操作列不输出。导出的文本字段会防止表格软件按公式执行，CSV 回导会还原该转义。

CSV 在浏览器中先按严格 UTF-8 解码，失败时尝试 GBK；用户可手动指定编码。表头可自动或手动映射。预览只用于提示，服务端会在提交时重新校验。默认有任何无效行就拒绝整批写入；选择跳过无效行时，服务端只提交有效行，并返回导入数、跳过数及原因。服务端在一次持久化中写入任务和停止状态的重复序列。

JSON 导入和 Markdown 导出维持原有接口与行为。
