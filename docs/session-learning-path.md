# 用户学习路径

会话页下方按聊天端用户 ID 选择学习路径。`GET /api/sessions/learning-path?userId=...` 需管理端登录，直接从 PostgreSQL 读取该聊天端用户的会话和 User 消息；按会话创建时间排列，Assistant 回复不参与提问阶段判断。页面展示会话时间线、阶段、技术主题、提问数，并可点击回到会话详情。聊天端用户 ID 不对应管理端账号。

当前是透明、可复现的关键词规则，**不是对用户知识水平的评分**。每个会话按其 User 提问中命中的最高阶段标注：基础概念（例如“是什么、入门、基础”）、进阶用法（例如“原理、性能、优化、架构”）、实战问题（例如“项目、实现、部署、报错”）；都未命中时显示“未识别”。另按明确的 React、TypeScript、Python、SQL、Agent、模型、API、Docker、Git 词汇标注主题。规则不使用 Assistant 回复、任务阶段或模型推断。

三类演进模式的判定口径：

- **线性深入**：至少三个可识别阶段的会话，阶段曾上升且没有下降。
- **广度拓展**：至少三个含主题的会话，共识别至少三个不同技术主题。
- **回退复习**：较高阶段之后出现了较低阶段；这只描述提问顺序，不表示能力倒退。

同一用户可同时出现多种模式；没有足够证据时不显示模式。规则测试覆盖三种模式、未识别、单会话不误报、跨用户隔离和时间排序。真实聊天可能含同义表达、跨主题问题和非学习问答，需由用户结合实际内容验收分类准确性；之后如需要，可引入经评测的数据集和语义分类器。
